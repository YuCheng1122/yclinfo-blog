# yclinfo.com

Tommy Lin 的個人網誌，用 [Astro](https://astro.build) 建置，部署在 [Vercel](https://vercel.com)。

## 開發

```sh
npm install
npm run dev
```

## 新增文章

在 `src/content/blog/` 新增一個 `.md` 檔案，詳見 [`src/content/blog/how-to-write-a-post.md`](./src/content/blog/how-to-write-a-post.md)。

## 部署

push 到 `main` branch，Vercel 會自動建置並部署。
